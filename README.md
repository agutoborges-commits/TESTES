A Abstração consiste em pegar um conceito do mundo real e mapeá-lo para dentro do código, isolando apenas as propriedades e comportamentos necessários.
O Encapsulamento serve para proteger os dados internos de uma classe, impedindo que outras partes do código façam alterações indevidas diretamente.
A Herança permite que uma classe herde comportamentos, propriedades e métodos de outra classe "mãe", evitando a repetição de código.
O Polimorfismo significa "muitas formas" e permite que um mesmo método ou comportamento funcione de maneiras diferentes dependendo do objeto que o está executando.
